# Voyeger — Frontend (Bhopal, India)

Voyeger is an offline-first, multilingual tourism guide for Bhopal, Madhya Pradesh, India.
Built by **Dharmesh Krish Mithaulia & Ujjval Rajauriya**.

## Development

```sh
cd frontend
npm install --legacy-peer-deps
npm run dev
```

## Production Build

```sh
cd frontend
npm run build
```
